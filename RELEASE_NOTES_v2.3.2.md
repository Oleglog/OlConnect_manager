# OlConnect Manager server-v2.3.2 — Интеграция кодека Batched (ZSTD), автосинхронизация подписок и очистка интерфейса

### Что изменилось:
1. **Поддержка кодека Batched (ZSTD + пачечная склейка)**:
   - В настройки инстансов OpenFlux добавлен выбор кодека: `Batched (ZSTD)` (по умолчанию) и `Legacy (LZ4)`.
   - Автоматическая генерация ссылок `openflux://` и QR-кодов с параметром кодека `&c=...` при необходимости.
2. **Автоматическая синхронизация инстансов в подписках**:
   - При изменении конфигурации инстанса, ротации ключа шифрования, комнаты или Client ID все привязанные подписки автоматически обновляются без необходимости ручного перепривязывания.
3. **Автоматические понятные имена для OpenFlux**:
   - Инстансы OpenFlux теперь по умолчанию именуются как `OpenFlux Mail.ru` или `OpenFlux Yandex` (вместо технического `openflux_olcrtc`).
4. **Очистка веб-интерфейса Admin UI**:
   - Удалён неиспользуемый чекбокс Debug logging.
   - Поле Auth Token отображается только для провайдера wbstream.
   - Скрыты дублирующиеся строки ключа шифрования и Client ID в карточках инстансов.
   - В модальном окне «Состав» отображаются бейджи других подписок, в которые входит инстанс (`В подписках: ...`).

### Как обновить сервер:
Для обновления выполните на сервере от `root`:
```bash
curl -fsSL https://raw.githubusercontent.com/Oleglog/OlConnect_manager/master/server-install/olcrtc-setup.sh | sudo bash -s -- --update
```
