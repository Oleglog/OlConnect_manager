# OlConnect Manager server-v2.3.3 — Релиз панели и сервера: Поддержка кодека Batched, фиксы Mail.ru и автосинхронизация подписок

Релиз **server-v2.3.3** приносит интеграцию высокоскоростного кодека **Batched (ZSTD)** в серверную часть, исправление передачи переменных окружения и прокси-параметров в лаунчер OpenFlux, а также автоматическое обновление связанных подписок.

---

### 🚀 Что нового и что было исправлено

#### 1. Поддержка кодека Batched (ZSTD) для инстансов OpenFlux
* **Кодек Batched по умолчанию**: Новые создаваемые инстансы OpenFlux (как Yandex, так и Mail.ru) по умолчанию работают в режиме высокой производительности `batched` (Zstandard + пакетирование).
* **Синхронизация конфигурации**: Исправлена рассинхронизация переменных окружения между панелью и системными скриптами. Менеджер одновременно экспортирует `OLCRTC_OPENFLUX_CODEC` и `OLCRTC_CODEC`, гарантируя запуск `openflux` в заданном режиме.
* **Селектор в интерфейсе панели**: При создании и редактировании инстанса OpenFlux доступен выбор кодека:
  * `Batched (ZSTD + пачки, рекомендуется)`
  * `Legacy (LZ4 per-packet)`
* **Генерация ссылок**: Ссылки `openflux://` и `olconnect://` генерируют параметр `&c=` при использовании нестандартных кодеков.

#### 2. Исправление прокси и запуска OpenFlux на сервере
* **Проброс параметров SOCKS5 и WARP**: В шаблон генерации `olcrtc-launcher` в установщике `olcrtc-setup.sh` добавлены флаги `--socks-proxy`, `--warp-proxy`, а также экспорт системных переменных `ALL_PROXY`, `HTTP_PROXY`, `HTTPS_PROXY`. Теперь выходная нода `openflux` может работать через вышестоящие прокси без ручного редактирования скриптов.
* **Корректные имена по умолчанию**: При создании инстансов генерируются понятные названия `OpenFlux Mail.ru` или `OpenFlux Yandex` вместо универсального `openflux_olcrtc`.

#### 3. Автоматическая синхронизация подписок и улучшения UI
* **Каскадное обновление инстансов в подписках**: При изменении параметров инстанса (ротация ключа шифрования, смена ссылки на документ, Client ID или смена кодека) все привязанные клиентские подписки обновляются автоматически в фоновом режиме.
* **Перекрестные ссылки на подписки**: В модальном окне «Состав» инстанса теперь отображается, в какие подписки включен данный инстанс (`В подписках: ...`).
* **Очистка интерфейса**: Скрыты неиспользуемые поля (поле Auth Token отображается только для провайдера wbstream, скрыт лишний чекбокс Debug logging, скрыты дублирующиеся строки ID и ключей в карточках).

### 📦 Инструкция по обновлению на VPS

Для обновления панели управления и всех системных скриптов выполните команду от `root`:

```bash
curl -fsSL https://raw.githubusercontent.com/Oleglog/OlConnect_manager/master/server-install/olcrtc-setup.sh | sudo bash -s -- --update
```

Или для изолированного обновления бинарника OpenFlux и лаунчера:
```bash
curl -fsSL https://raw.githubusercontent.com/Oleglog/OlConnect_manager/master/server-install/update-openflux.sh | sudo bash
```
