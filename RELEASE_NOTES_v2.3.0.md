# OlConnect Manager server-v2.3.0 — Крупный релиз интеграции OpenFlux и маршрутизации L3

Данный релиз объединяет и финализирует все наработки и исправления по интеграции провайдера **OpenFlux** (Mail.ru Docs и Yandex Docs), прозрачной маршрутизации трафика и управлению ключами шифрования.

---

### 🚀 Что нового и что было изменено

#### 1. Выходная нода OpenFlux и прозрачная маршрутизация L3
* **Режим L3 по умолчанию**: Запуск exit-ноды `openflux` через `olcrtc-launcher` теперь строго выполняется с параметром `--mode l3`. Это включает прозрачную трансляцию сырых пакетов через Linux raw-сокеты (`syscall.SOCK_RAW`), гарантируя, что весь интернет-трафик клиентов (Telegram, мессенджеры, браузеры) корректно проходит через публичный IP-адрес сервера.
* **Автоматическая настройка сетевого стека ядра**:
  * Включение `sysctl -w net.ipv4.ip_forward=1` при старте службы.
  * Автоматическое добавление правила `iptables -I OUTPUT 1 -p tcp --tcp-flags RST RST -j DROP` (с поддержкой ограничения по `OLCRTC_LOCAL_IP`), предотвращающего сброс установленных TCP-сессий со стороны ядра Linux.
  * Настройка системных возможностей службы systemd (`CAP_NET_RAW`, `CAP_NET_ADMIN`, `CAP_NET_BIND_SERVICE`).

#### 2. Автоматическое обновление и загрузка бинарников OpenFlux
* **Авто-загрузка на лету**: Если бинарник `/usr/local/bin/openflux` отсутствует при первом старте инстанса, `olcrtc-launcher` автоматически скачивает актуальный релиз под текущую архитектуру (`amd64` или `arm64`) из репозитория `Oleglog/OpenFlux-Android`.
* **Фоновая проверка обновлений**: При перезапуске инстансов служба проверяет наличие более свежего тега на GitHub и автоматически обновляет бинарник.
* **Автономный скрипт быстрого обновления**:
  ```bash
  curl -fsSL https://raw.githubusercontent.com/Oleglog/OlConnect_manager/master/server-install/update-openflux.sh | sudo bash
  ```
  Позволяет обновить OpenFlux, лаунчер и перезапустить все сервисы в одну команду.
* **Интеграция в `olcrtc-setup.sh`**:
  * Добавлен флаг `sudo bash olcrtc-setup.sh --update-openflux`.
  * При общем обновлении `sudo bash olcrtc-setup.sh --update` бинарник OpenFlux обновляется вместе с панелью и ядром.
  * Исправлена верификация контрольных сумм SHA-256 с разделением по архитектурам хоста.

#### 3. Управление шифрованием OpenFlux AES-256-GCM в Admin UI
* **Веб-панель управления**: В интерфейсе создания и редактирования инстанса добавлено поле «Ключ шифрования OpenFlux» с кнопкой генерации криптографически стойкого случайного ключа.
* **Экспорт конфигурации**: Сгенерированный ключ автоматически подставляется в ссылку `olconnect://` и QR-код для моментального бесшовного импорта на мобильных устройствах.
* **Совместимость**: Ключ шифрования строго опционален и больше не подменяется внутренним ключом olcRTC.

### 📦 Инструкция по обновлению сервера

Для обновления сервера и всех инстансов OpenFlux до версии **server-v2.3.0** выполните в терминале сервера от `root`:

```bash
curl -fsSL https://raw.githubusercontent.com/Oleglog/OlConnect_manager/master/server-install/update-openflux.sh | sudo bash
```
