# OlConnect Manager server-v2.3.4 — Релиз: Интеграция статуса и обновления OpenFlux в Admin UI

Релиз **server-v2.3.4** выносит отдельный блок управления и обновления бинарников **OpenFlux (Exit-Node)** прямо в веб-интерфейс панели администратора.

---

### 🚀 Что нового

#### 1. Управление бинарником OpenFlux в Admin UI
* **Карточка статуса OpenFlux**: В разделе «Настройки» &rarr; «Обновления» добавлен наглядный блок «Бинарник OpenFlux (Exit-Node)»:
  * Отображение установленной версии (например, `v1.0.2` или статус «установлен» / «не установлен»).
  * Проверка актуального релиза на GitHub (`Oleglog/OpenFlux-Android`).
  * Бейджи статуса: зелёный при актуальной версии, синий при наличии обновления, жёлтый при отсутствии файла.
* **Кнопка обновления в один клик**: Позволяет обновить `/usr/local/bin/openflux` до актуальной версии прямо из браузера без входа по SSH.
* **Автоматическая верификация и перезапуск**: При обновлении скачивается релиз под архитектуру сервера (`amd64` / `arm64`), проверяется контрольная сумма SHA-256 и мягко перезапускаются все активные инстансы `openflux@*`.

#### 2. REST API эндпоинты
* `GET /api/system/openflux/status` — возвращает информацию об установленной и доступной версиях OpenFlux.
* `POST /api/system/openflux/update` — выполняет скачивание, сверку хеша и замену бинарника на лету.

### 📦 Инструкция по обновлению на VPS

```bash
curl -fsSL https://raw.githubusercontent.com/Oleglog/OlConnect_manager/master/server-install/olcrtc-setup.sh | sudo bash -s -- --update
```
